Before / after

Current experience Short match pacing, commentary and dynamic simulation visuals.
Proposed enhancement Same pacing, but with clearer pitch thirds, event cards and short contextual 2D key moments.

The proposal is an enhancement layer, not a replacement for the existing match engine or match flow.

How the interaction works

1
Normal playOnly the active third pulses. The ball stays hidden.
2
Meaningful event detectedThe match switches temporarily to key-moment mode.
3
Contextual visualisationRelevant players, ball path and event card appear briefly.
4
Return to normal flowThe screen goes back to the simple OSM-like match monitor.

Design boundary

This is a UX concept only. It does not assume OSM's internal architecture, event schema or implementation language. The animations are scripted solely to communicate how an enhancement could feel to the player.
